BackType v0.1.1

- Adds an editable Text parameter in Effect Controls using a small custom text row.
- Adds Text Source with Plugin Text and Layer Text options. Plugin Text is the working mode for now.
- Changes the default Anchor Mode to Center Locked.
- Fixes descender letters like y, g, j, p, and q shifting the text upward while typing.
- Keeps the macOS release package separate from the Windows package.
